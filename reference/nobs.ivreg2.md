# Extract number of observations from an ivreg2 object

Extract number of observations from an ivreg2 object

## Usage

``` r
# S3 method for class 'ivreg2'
nobs(object, ...)
```

## Arguments

- object:

  An object of class `"ivreg2"`.

- ...:

  Additional arguments (ignored).

## Value

Integer: number of observations.
