# Extract coefficients from an ivreg2 object

Extract coefficients from an ivreg2 object

## Usage

``` r
# S3 method for class 'ivreg2'
coef(object, ...)
```

## Arguments

- object:

  An object of class `"ivreg2"`.

- ...:

  Additional arguments (ignored).

## Value

Named numeric vector of coefficient estimates.
