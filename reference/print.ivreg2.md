# Print an ivreg2 object

Print an ivreg2 object

## Usage

``` r
# S3 method for class 'ivreg2'
print(x, digits = max(3L, getOption("digits") - 3L), ...)
```

## Arguments

- x:

  An object of class `"ivreg2"`.

- digits:

  Minimum number of significant digits to print.

- ...:

  Additional arguments (ignored).

## Value

`x`, invisibly.
